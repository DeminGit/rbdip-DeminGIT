## Как проверять

Нужны Java 21, Maven, Python 3 и работающий Docker с Linux-контейнерами.

```sh
mvn clean verify
mvn org.pitest:pitest-maven:mutationCoverage
python scripts/write_score.py
```

Смотрите все `gates.*.passed` и `score = 100` в score.json, а также отчёты
JUnit в target/surefire-reports (ни ошибок, ни пропущенных тестов), Checkstyle,
PMD, JaCoCo и PIT. В исходной конфигурации BUILD SUCCESS и зелёный Actions
не гарантируют прохождение тестов: ошибки допускаются настройками Maven/CI.
В GitHub откройте Actions → запуск для нужного SHA → артефакты score и reports.
